## 標準コンポーネントを優先する

新規コンポーネントを実装する前に、フレームワーク / UI ライブラリ標準に同等のものがないか先に検討する。標準で足りないスタイル要件はテーマで吸収し、標準では実現不能な要件があるときに初めて自前で組む。

**理由:** ゼロから組み上げるとアクセシビリティ / テーマ連動 / アニメーション等をすべて自前で再現する必要があり保守コストが高い。
