# Notion 貼り付け用の出力

正本の md（`docs/requests/YYYY-MM-DD-<短い名前>.md`）から、Notion にそのまま貼り付けられる `<同じ名前>.notion.md` を作る。中身は正本と同じにし、Notion で崩れる書き方だけを直す。正本を直したら、Notion 用も作り直す。

## 変換のルール

1. **frontmatter を表にする**：Notion は frontmatter を文字のまま表示してしまうので、冒頭の `---` で囲まれた部分を消し、次の表に置き換える

   ```markdown
   | 項目 | 内容 |
   |---|---|
   | 依頼者 | 山田（ユーザーサポート） |
   | 日付 | 2026-11-01 |
   | 状態 | 合意済み |
   | 種別 | 既存機能の改善 |
   | 関係する画面 | 請求書一覧画面 |
   | 優先度 | 高 |
   | 期限 | なし |
   | 要確認 | 1件 |
   ```

   `status` は `draft` → 「ヒアリング中」、`ready` → 「合意済み」と日本語にする。`type` と `repository` は載せない（エンジニア向けの印のため）

2. **HTML コメントを消す**：`<!-- -->` は Notion でそのまま表示されるので削除する
3. **見出しの「→ spec-interview ...」を消す**：仕様設計の手順との対応はエンジニア向けの情報なので、Notion 用では見出しから外す（例：`## 1. 困りごと（→ spec-interview Phase 1：課題）` → `## 1. 困りごと`）
4. **引用（`>`）はそのまま使う**：Notion では引用ブロックになる
5. **表・箇条書き・チェックボックス・見出しはそのまま**：Notion の Markdown 貼り付けで崩れない
6. **ファイルのパスは残す**：Notion を見るエンジニアの参考になるため。ただし、ローカル PC の絶対パス（`/Users/...`）は書かない

## 依頼者への案内

出力したあと、次のように伝える。

> Notion 用のファイルは `<ファイルのパス>` です。ファイルを開いて中身をすべてコピーし、Notion のページに貼り付けると、見出しや表がそのまま反映されます。
