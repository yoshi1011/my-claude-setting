## 各層の責務

| 層 | 書いてよいこと | 書いてはいけないこと |
| --- | -------------- | -------------------- |
| Controller | リクエストパース / 1 つの Usecase 呼び出し / レスポンス組み立て | ビジネスルール、DB アクセス、複数 Usecase の合成 |
| Usecase | Repository/Query 呼び出し、Domain 利用、トランザクション境界 | DB の直接アクセス、HTTP 知識（params / cookies）への依存 |
| Domain | 問題領域のルール / 計算 / 不変条件 | DB アクセス、ORM メソッドの直接呼び出し |
| Repository | create / update / destroy / 状態変更 | 検索系クエリ |
| Query | 検索 / 存在確認 / 集計 | 書き込み |
| ORM モデル | 関連 / 宣言 / DB 制約で吸収できない最小バリデーション | カスタムメソッド（基本書かない） |
